# Розробка 2D гри в жанрі пригодницький бойовик «Shōgun no Kage»

Кваліфікаційна робота на підтвердження ступеня фахового молодшого бакалавра (ВСП «ППФК НТУ «ХПІ» (http://polytechnic.poltava.ua)/). Керівник роботи – Олійник Владислав Васильович.

## Завдання до дипломної роботи
Розроблений програмний продукт має являти собою 2D-гру в жанрі пригодницький бойовик розроблений за допомогою рушія Unreal Engine. Основна мета гравця – розвивати своє господарство(ферму). Розробку виконати за допомогою Blueprint та PaperZD. Слід подбати про зручне меню та наявність рівнів, реалізувати взаємодію з іншими персонажами та навколишнім світом(дерева, кущі, тощо), реалізувати інвентар(склад), тощо. Готовий продукт опублікувати в одному з онлайнових ігрових магазинів (gamejolt тощо).

## Використані технології
- Unreal Engine 5.7
- Blueprint (основна логіка)
- Paper2D / PaperZD (2D-анімації)
