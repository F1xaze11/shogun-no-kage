# Розробка 2D гри в жанрі пригодницького бойовика «Shōgun no Kage»

Кваліфікаційна робота на підтвердження ступеня фахового молодшого бакалавра (ВСП «ППФК НТУ «ХПІ» (http://polytechnic.poltava.ua)/). Керівник роботи – Олійник Владислав Васильович.

## Завдання до дипломної роботи
Розроблений програмний продукт має являти собою 2D-гру в жанрі пригодницького бойовика, створену за допомогою ігрового рушія Unreal Engine. Основна мета гри полягає у проходженні ігрових рівнів, боротьбі з ворогами та поступовому просуванні героя до фінального протистояння з головним антагоністом. Гравець керує персонажем-самураєм, який подорожує різними локаціями та вступає в бої з противниками.

Розробку необхідно виконати з використанням системи Blueprint для реалізації ігрової логіки та PaperZD для створення й керування двовимірними анімаціями персонажів. У грі необхідно реалізувати систему керування персонажем, бойову систему, систему здоров’я, взаємодію з ворогами, базовий інтерфейс користувача, а також декілька ігрових рівнів із міні-босами та фінальним босом.
Окрему увагу слід приділити структурі проєкту, зручності керування, візуальному оформленню та стабільності роботи програми. 

Готовий продукт опублікувати в одному з онлайнових ігрових магазинів (gamejolt тощо).

## Використані технології
- Unreal Engine 5.7
- Blueprint (основна логіка)
- Paper2D / PaperZD (2D-анімації)
